## 次回の告知の型（提案）

- **開始の告知は静止画（作品一覧＋受付期間）を主役にする。** 21時ごろに出す（2回とも21時前後で結果が出ている）。
- **作品ごとの動画は残す。ただし「人を呼ぶ」役ではなく「絵の感じを伝える」役として出し方を変える。**
  - 静止画では筆致・質感・光の当たり方が伝わりにくく、買うか迷っている人の判断材料として動画は必要（2026-10-14 の相談で確認）。
  - 数字が示しているのは「動画は新しい人を連れてこない・クリックの山を作らない」ことだけで、すでに興味を持った人への効き目は測れていない。
  - 興味が一番高いのは開始直後の2日間なので、動画は**開始日〜翌日にまとめて見られる状態にする**。案は次のどちらか。
    - 開始の静止画の直後に、作品ごとの動画をまとめたカルーセル（動画と画像を混ぜられる）を1本出し、プロフィールに固定する
    - 動画を個別に出す場合も、開始日〜翌日に寄せて出し、リール用のハイライト（またはストーリーズ）にまとめて、ショップから戻ってきた人がすぐ見られるようにする
  - 毎日1本ずつ間をあけて出すやり方は、リーチもクリックも増えなかったうえに手間が大きいので、やめてよい。
- **締切の前日か当日に、リマインドの静止画を1本出す。** 「受付は明日20時まで」と作品一覧をもう一度見せる。
- **予告の投稿は残す。** 7/14 の準備中の投稿はリーチこそ平常並みだが、告知の前にフォロワーに知らせておく役割がある。
- 案としては「予告 → 開始の静止画 → 作品動画のカルーセル（固定）→ 締切リマインドの静止画 → 完売報告」の4〜5本で、2〜3週間に収まる。

## 留意点

- **アカウント日次の日付は1日ずれている。** `date` は収集日（毎日0時に実行）で、中身はほぼ前日の夜〜当日0時までの24時間ぶん。7/24 21時の告知の効果は 7/25・7/26 の行に出る。
- アカウント日次は 2026-06-07 からしか無いため、前回（2025-11）のクリック推移は比べられない。
- 動画を出さなかった場合のクリックの減り方は観測していない。また、動画が応募の決め手になったか（絵の感じが伝わったか）は API の数字では測れない。数字から言えるのは「毎日1本ずつ出してもリーチ・クリックの上積みは出ていない」ことまで。
- 2回分の比較で、相関であって因果ではない。次回は上の型で出して、今回のクリック推移と比べると確かめられる。
