# 写真収集・許諾まわりの文面テンプレート

GALLERY事例を増やし続けるための3点セット。
集めた写真はショップGALLERYとInstagramリポストの両方で使えるよう、許諾は共通で取る。

## 1. 許諾依頼DM（Instagramでタグ付け・メンション投稿を見つけたとき）

```
◯◯さま

こんにちは、森山楓です。
作品を素敵に飾ってくださって、投稿まで…！本当にありがとうございます。とても嬉しいです。

もしよろしければ、こちらのお写真を
・ショップサイトの「作品展示例」ページ
・私のInstagram（リポスト）
でご紹介させていただけないでしょうか。

掲載の際のお名前は、
1. Instagramのお名前
2. イニシャルや別のお名前
3. 匿名
のいずれでも大丈夫です。ご希望をお聞かせください。

もちろん、掲載を希望されない場合もまったく問題ありません。
これからもどうぞよろしくお願いいたします。
```

## 2. 同梱カード文面（発送時に入れる小さなカード）

```
このたびは作品をお迎えいただき、ありがとうございます。

飾った様子のお写真を、ぜひ見せていただけたら嬉しいです。
Instagram @moriyamakaede のタグ付け、またはDMでお送りください。
いただいたお写真は、ご希望を確認のうえ
ショップの「作品展示例」ページでご紹介させていただくことがあります。

森山楓
```

（名刺サイズ〜ハガキサイズ。裏面にInstagramのQRコードを入れると導線が強くなる）

## 3. 抽選当選者へのサンクスメッセージ（発送連絡に追記する一文）

```
作品が届きましたら、飾った様子をぜひ見せてください。
Instagram（@moriyamakaede）のタグ付けやDMでお送りいただけたら、
とても励みになります。
```

## 運用メモ

- 許諾が取れたら、表記名・使用範囲（ショップ／Instagram）をスプレッドシート等で記録しておく（後から確認できるように）
- リポスト時はキャプションに「◯◯さんが飾ってくださいました」＋作品名を入れる（Instagram側の保存率素材としても機能）
