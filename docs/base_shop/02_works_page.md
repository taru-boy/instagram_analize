# WORKS（作品ポートフォリオ）ページ構成案

新設: ページ追加Appで作成（/p/00002 になる想定）。ナビ表記は「WORKS」。

## ねらい

- HOME＝売り場、GALLERY＝お客様の飾り方、に対して **WORKS＝作家の作品歴**
- SOLD OUT商品ページ（レビュー・価格実績つき）へリンクして「販売実績込みのポートフォリオ」にする
- ショップ開設前の旧作も載せられる（商品一覧にはできないこと）

## 運用ルール

- シリーズの並び順は**新しいシリーズが上**（「今」が最初に見える）
- 1作品分のフォーマット：写真＋『作品名』（リンク）＋制作年。シリーズ紹介文はシリーズ単位で1つ
- 新シリーズの抽選販売が終わったタイミングでWORKSに追記する（月間サイクルに組み込む）
- シリーズ紹介文は妻に1〜2文ずつもらう（ここだけは本人の言葉が必要）
