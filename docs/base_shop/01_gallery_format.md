## 1事例のフォーマット（これに統一する）

```
（写真）

『作品名』 → 商品ページへのリンク
飾り方：ミニイーゼル／リビングのチェストの上
◯◯さんより「（ひとことコメント。あれば）」
```

記載ルール:
- **作品名は必ず商品ページへリンク**する（SOLD OUTでもOK。作品詳細・サイズ・レビューが見られる）
- 飾り方は「手段（イーゼル／押しピン／ひっつき虫／額装）＋場所（玄関・寝室・デスクなど）」の2要素
- お名前は掲載許諾時の希望表記に従う。希望がなければイニシャル
- コメントは任意。もらえた場合のみ「」で載せる
